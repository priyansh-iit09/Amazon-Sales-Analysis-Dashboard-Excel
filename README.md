# Amazon Sales Analysis Dashboard 📊

##  Project Overview
This project focuses on analyzing Amazon sales data using Microsoft Excel. An interactive sales dashboard has been developed to transform raw sales data into meaningful business insights through data analysis and visualization.

The dashboard helps understand sales performance, profit trends, product categories, and regional sales distribution.

##  Project Objectives
- Analyze overall sales and profit performance.
- Track monthly sales trends.
- Compare sales across different regions.
- Analyze category-wise sales performance.
- Identify product-wise sales and profit contributions.
- Present business insights through visual dashboards.

##  Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Analysis
- Data Visualization
- Dashboard Creation

##  Dataset Information
The dataset contains 1,500 records with information such as:
- Order ID
- Order Date
- Customer Name
- Country and City
- Region
- Product Category
- Product Name
- Sales
- Quantity
- Discount
- Profit

## 📈 Dashboard Analysis
The project includes the following analysis:

1. **Monthly Sales Analysis** – Understand sales performance month by month.
2. **Region-wise Sales Analysis** – Compare sales across different regions.
3. **Category-wise Sales Analysis** – Analyze the contribution of different product categories.
4. **Product Sales Analysis** – Evaluate product-wise sales, profit, and quantity.
